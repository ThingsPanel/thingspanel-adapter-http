# 项目全局信息

## 项目简介

`thingspanel-adapter-http` 是 ThingsPanel HTTP 协议接入插件，用于接收设备通过 HTTP POST 上报的遥测数据，并转发到 ThingsPanel 平台。当前项目同时包含设备侧协议 HTTP 服务和平台侧回调 HTTP 服务。

## 技术栈

- Go 1.22
- `github.com/ThingsPanel/tp-protocol-sdk-go`：平台回调 SDK
- `github.com/spf13/viper`：配置加载
- `github.com/sirupsen/logrus`：日志
- `gopkg.in/natefinch/lumberjack.v2`：日志滚动

## 目录结构说明

- `cmd/main.go`：程序入口。
- `configs/config.yaml`：默认配置。
- `internal/bootstrap/`：应用启动、配置、日志、平台客户端、HTTP 服务初始化。
- `internal/protocol/`：设备协议抽象、HTTP 协议服务、协议生命周期。
- `internal/protocol/plugins/examples/`：当前 HTTP 示例协议解析器。
- `internal/handler/`：ThingsPanel 平台回调处理器。
- `internal/platform/`：平台 API、MQTT 和设备操作客户端。
- `internal/form_json/`：平台表单 JSON 内嵌资源。
- `docs/`：部署、日志、设备标识等说明文档。

## 核心模块表

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| 应用启动 | `internal/bootstrap/app.go` | 加载配置、启动心跳、设备协议服务和平台回调服务 |
| 设备协议 HTTP 服务 | `internal/protocol/http_handler.go` | 在 `server.port` 上接收设备上报并转发遥测 |
| 协议生命周期 | `internal/protocol/handler.go` | 管理协议处理器启动、停止和状态 |
| HTTP 示例协议解析 | `internal/protocol/plugins/examples/http_demo.go` | 解析设备 JSON 上报数据 |
| 平台回调 HTTP 服务 | `internal/bootstrap/http.go` | 在 `server.http_port` 上承载平台回调和健康检查 |
| 平台回调处理 | `internal/handler/handler.go` | 注册 SDK 回调处理器 |
| 平台客户端 | `internal/platform/platform.go` | 查询设备、动态注册、遥测上报、心跳 |
