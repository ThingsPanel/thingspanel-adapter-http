# 控制消息订阅交付

## 问题概述

修复了 `plugin/HTTP/devices/telemetry/control/D001` 控制消息无法被插件订阅的问题。

## 修复内容

- 控制订阅 topic 调整为 `plugin/{service_identifier}/devices/telemetry/control/+`。
- 控制消息使用 topic 最后一段作为 `device_number`。
- 平台客户端初始化时注册默认控制处理器，启动后自动订阅控制消息。

## 验证结果

已执行：

```powershell
go test ./...
```

## 影响说明

收到控制消息后当前行为是写日志，不下发到 HTTP 设备。HTTP 设备是请求上报模型，后续如需真正控制设备，需要设计设备取指令或长连接能力。

## 注意事项

- 发布 topic 示例：`plugin/HTTP/devices/telemetry/control/D001`。
- payload 必须是 JSON 对象，例如 `{"xx":11}`。
