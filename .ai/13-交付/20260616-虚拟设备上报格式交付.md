# 虚拟设备上报格式交付

## 问题概述

虚拟设备已从旧 TCP 二进制上报改为 HTTP JSON 上报，不再要求设备提供平台设备 ID。

## 修复内容

- `cmd/virtual_device/main.go`：改为请求 `POST /api/v1/uplink`，payload 使用 `device_number`。
- `configs/config.yaml`：默认 `server.http_api_key` 调整为 `aaaabbbb`。
- `README.md`、`README_CN.md`：上报示例调整为 `device_number=D001` 和 `Access-Token=aaaabbbb`。

## 验证结果

已执行：

```powershell
go test ./...
```

旧实现残留检索无结果：

```powershell
rg -n "deviceID|device_id|net\.Dial|encoding/binary|tcp|buildDataPacket|calculateChecksum" cmd\virtual_device\main.go
```

## 影响说明

虚拟设备现在用于验证当前 HTTP 插件链路。默认上报示例等价于：

```powershell
curl.exe -X POST http://127.0.0.1:19090/api/v1/uplink `
  -H "Content-Type: application/json" `
  -H "Access-Token: aaaabbbb" `
  -d "{\"device_number\":\"D001\",\"temp\":25.5,\"hum\":60.2,\"status\":\"active\"}"
```

## 注意事项

- 真实上报仍需要平台服务和 MQTT 服务可用。
- 如服务端 `server.http_api_key` 改变，虚拟设备需通过 `-token` 传入一致的值。
