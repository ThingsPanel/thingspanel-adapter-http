# 虚拟设备上报格式缺陷

## 问题描述

虚拟设备仍使用旧的 TCP 二进制协议上报，并以 `uint32` 设备 ID 构造数据包。当前 HTTP 插件要求设备通过 `POST /api/v1/uplink` 上报 JSON，设备标识必须是 `device_number`，例如 `D001`。

## 影响范围

- `cmd/virtual_device/main.go`
- 使用虚拟设备验证 HTTP 上报链路的本地测试流程

## 根因分析

虚拟设备代码没有随 HTTP 上报入口调整同步更新，仍保留早期 TCP 模拟器实现：

- 使用 `net.Dial("tcp")` 连接协议端口。
- 使用 4 字节 `deviceID` 构造二进制包。
- 没有发送 `Access-Token` 请求头。
- 没有按 `/api/v1/uplink` 的 JSON 格式携带 `device_number`、`temp`、`hum`、`status`。

## 相关代码

- `cmd/virtual_device/main.go`

## 待确认问题

无。用户已明确正确示例为 `device_number=D001`，请求头为 `Access-Token: aaaabbbb`。
