# 虚拟设备上报格式修复方案

## 修复策略

将虚拟设备从 TCP 二进制模拟器改为 HTTP JSON 上报器，直接模拟真实设备调用 `/api/v1/uplink`。

## 改动清单

- `cmd/virtual_device/main.go`
  - 删除 TCP 连接、二进制数据包、平台设备 ID 相关逻辑。
  - 新增 HTTP POST 上报逻辑。
  - 默认设备编号改为 `D001`。
  - 默认上报地址改为 `http://localhost:19090/api/v1/uplink`。
  - 默认 `Access-Token` 改为 `aaaabbbb`。
- `configs/config.yaml`
  - 默认 `server.http_api_key` 改为 `aaaabbbb`。
- `README.md`、`README_CN.md`
  - 同步设备上报示例。

## 风险评估

- 旧 TCP 虚拟设备行为被移除；当前项目为 HTTP 接入插件，该行为不再符合需求。
- 多设备模式会按起始设备编号递增，例如 `D001`、`D002`。

## 测试计划

- 执行 `go test ./...` 确认编译通过。
- 检索虚拟设备中旧 TCP 和 `deviceID` 残留。
- 使用虚拟设备命令进行实际 HTTP 上报验证。
